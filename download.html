Installationsanleitung (Android)

  1. APK herunterladen: Klicke auf den grünen Download-Button oben.
  2. Installation bestätigen: Öffne die heruntergeladene Datei coinring-legends.apk im Benachrichtigungsfeld oder Download-Ordner.
  3. Installation aus unbekannten Quellen erlauben: Falls Android warnt, tippe auf "Einstellungen" und aktiviere "Apps aus dieser Quelle zulassen".
  4. Fertigstellen: Tippe auf "Installieren" und starte Coinring Legends direkt auf deinem Startbildschirm!
